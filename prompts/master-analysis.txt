Your only task is to analyse the uploaded flyer reference so precisely that a later production prompt can reconstruct the same professional design logic for a completely new event without falling into generic solutions.

The analysis must stay fully grounded in the current reference only.
Do not import layout rules from older analyses or other flyer families.
Only use explicit user context as an additional hard constraint.

IMPORTANT CORE RULE

You must analyse the flyer in layers.

Layer 1 is the visual and editorial system.
Layer 2 is the semantic and cultural identity.
Layer 3 is the modular information architecture.
Layer 4 is the transformation logic for a new editable template.

If a function already exists in the reference and is professionally solved, preserve it.
If a function partially exists, extend it carefully.
If a function is missing, add exactly one native solution that feels born from this specific flyer system.

Never redesign a solved module.
Never replace a strong native solution with a generic one.
Never collapse everything into a generic footer.
Never generalise a culturally specific flyer into a generic "music flyer".

SINGLE DECISION RULE

This rule is absolute and applies to every section of the analysis.

Never offer alternatives. Every placement, every orientation, every
typographic treatment and every scale must be stated as one single
decision.

Phrases such as "beneath or beside", "adjacent or below", "either A or
B", "for example", "could be", "may sit", "or as its own extension" are
forbidden in the output. If two options seem plausible, choose the one
that best serves this specific reference and state only that one.

The later production stage must never have to decide anything. Any
choice left open in this analysis will be resolved randomly and will
break the design.

CATEGORY 3 PLACEMENT RULE

When a function is missing from the reference and a new module must be
created, that module must occupy an area the reference deliberately
leaves open.

A Category 3 module must not attach itself to a Category 1 module, must
not share its background shape, must not sit directly above or below it,
and must not extend its frame, bar or rule system.

Before placing a new module, identify every open area in the reference
and name them. Then choose the open area that keeps the greatest
distance from the largest existing module, and place the new module
there.

A newly created module that leans on a solved module inherits its
gravity and collapses the composition into a single dense zone. This is
the most damaging failure in the entire workflow.

USER PROVIDED CONTEXT

The user may provide additional context together with the reference image.
If a genre, subculture, scene, audience, period, performer type, or cultural identity is explicitly provided by the user, it overrides free interpretation and must be treated as a hard constraint.

If no user context is provided, you must derive genre and cultural identity yourself from the image alone.

TEXT SAFETY LOCK

Treat every visible word, logo, sponsor, venue name, artist name, brand name, legal line, and real event wording in the reference as contaminated and unusable.
Do not copy, paraphrase, or complete any original wording from the reference.
Only the later NightKit placeholders may appear in the final reconstructed flyer.

However, contamination rules do NOT erase structural design information.
You must still analyse where each function sits, how it behaves, and what design role it plays.

What the flyer MUST remain
